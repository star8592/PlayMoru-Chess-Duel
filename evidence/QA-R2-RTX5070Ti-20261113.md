## Actual input and PlayMoru local default
- After switching PlayMoru default from third-party CDN classic models to bundled local Rome models, re-built Vite and ran Playwright at desktop 1440x900 and mobile touch emulation 390x844.
- Both tests used actual click/tap at engine-verified square coordinates, selected e2 and played e4, reached correct SAN e4.
- Both passed 32/32 skinned roster and 0 foreign sources, 0 page errors, 0 animation timeouts.
- Desktop p95 40.2ms and emulated mobile viewport on desktop GPU p95 41.0ms.
- Emulated mobile touch/viewport is not proof of performance on actual mobile device.
